Interpreted Programming Language

Write code, run it in your browser. The interpreter is compiled to WebAssembly, so nothing is sent to a server.

About the language

IPL is a statically typed interpreted language with a lexer, parser, type checker and tree-walking executor, written in C++23. Programs are checked for type errors before they run, so most mistakes are reported before any code executes.

How to use this page

  • Type or paste code into the Code panel, or pick a program from the Examples menu.
  • Press Run or use Ctrl + Enter. Output and error messages appear in the Output panel.
  • Everything runs locally in your browser, so a program with an infinite loop can freeze this tab. Reload the page if that happens.
Syntax quick reference
  • Statements end with a semicolon: print("hello");
  • Types: void, bool, int, float, double, string
  • Variables: C-style declarations int i = 0; string s = "foo"
  • Operators: +, -, *, /, =, !, %, ==, !=, +=, -=, *=, /=
  • Control flow: if statements, while loops
    if ( foo ) { # If foo is true } else { # if foo is false }
    while ( foo ) { # Executes this code while foo is true }
  • Functions: Pass arguments as value, recursion is allowed.
    fn foo(int faz) -> void { # Function body }
  • Comments: #This is a comment
  • Objects: Objects allow to store multiple variables
    object Person { int age; string name; }
    Person tom = { 20, "Tom"};
    tom.age += 1;
  • Casting: Built in casting functions
    int i = int(11.12);
    string eleven = string(i);
